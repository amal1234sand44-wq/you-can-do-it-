# You Can Do It! — Android v2

نسخة مطوّرة من التطبيق تشمل:
- جدول جامعي أسبوعي كامل (اليوم، المادة، الوقت، القاعة).
- مهام الدراسة والواجبات والاختبارات والأمور الشخصية مع موعد وأولوية.
- إعادة تخطيط تلقائية عند إضافة/إنجاز/حذف مهمة، وزر لإعادة بناء خطة اليوم.
- حفظ البيانات محليًا حتى بعد إغلاق التطبيق.
- اختيار PDF/Word/PowerPoint/صور/صوت.
- تسجيل المحاضرات من داخل التطبيق وحفظها كملفات صوتية.
- تحليل محلي أولي للملفات والتسجيلات وربطها بمهام مراجعة.

## بناء APK
افتح المشروع في Android Studio ثم:
Build → Build APK(s)

> ملاحظة: التحليل الحقيقي لنصوص PDF/Word والتفريغ الصوتي الكامل يحتاج محرك OCR/STT أو خدمة AI وربط API. هذه النسخة جهزت البنية والواجهة والربط بالخطة دون وضع مفتاح API داخل التطبيق.


## البناء من الهاتف فقط
هذا المشروع يحتوي على GitHub Actions جاهز لبناء APK تلقائيًا. ارفعي المجلد إلى مستودع GitHub، ثم افتحي تبويب Actions وشغّلي Build You Can Do It APK. بعد نجاح العملية حمّلي artifact باسم YouCanDoIt-debug-apk وافكيه للحصول على app-debug.apk.

ملاحظة أمنية: مفتاح OpenAI لا تضعيه داخل المستودع أو الكود. التطبيق الحالي يحفظ المفتاح محليًا على الجهاز عند إدخاله. للاستخدام العام يفضّل إضافة خادم وسيط لحماية المفتاح.
